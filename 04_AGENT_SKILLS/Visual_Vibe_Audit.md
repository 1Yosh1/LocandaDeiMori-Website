# Skill: Visual Vibe Audit 🍋🏺

## Objective
Ensure the digital presence of Locanda dei Mori remains premium, artisanal, and authentically Sicilian.

## Evaluation Criteria
1. **Palette Check**:
   - Are colors within the "Pastel Sicilian" range? (Muted Lemon, Sage Green, Dusty Cobalt).
   - Avoid: High-saturation primaries or "cheap" vibrant tones.
2. **Iconography**:
   - Use custom SVG icons (Testa di Moro, Cactus).
   - Avoid: Generic library icons that feel "stock".
3. **Texture & Pattern**:
   - Presence of subtle Majolica patterns (opacity < 5%).
   - Use of artisanal photographic assets (plates, ceramics).
4. **Typography**:
   - Script fonts used for editorial accents only.
   - Serif fonts for headings (Playfair Display).
   - Clean sans-serif for body (Inter).

## Execution Steps
1. Review the target file's CSS/Tailwind classes.
2. Cross-reference with `globals.css` theme variables.
3. Suggest specific hex code swaps if saturation is too high.
4. Recommend "editorial" spacing or alignment improvements.

## Output Format
- **Vibe Score**: (1-10)
- **Saturation Audit**: List of colors that are too "loud".
- **Artisanal Recommendations**: Specific assets or patterns to add.
