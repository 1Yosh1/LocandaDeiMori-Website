# Tech Stack: Locanda Dei Mori Digital Ecosystem

## Frontend
- **Framework**: Next.js (App Router) for SSR/SSG and optimal SEO.
- **Styling**: Vanilla CSS with CSS Modules or Styled Components (Zero-generic utility bloat).
- **Animations**: GSAP & Framer Motion.

## Backend / Infrastructure
- **Database**: Supabase (PostgreSQL) for real-time bookings and CMS.
- **Auth**: Supabase Auth (PKCE flow).
- **Logging**: Winston or Pino for structured server-side logging.
- **Deployment**: Vercel (Edge Functions for speed).

## Design Tools
- **Generation**: Midjourney/DALL-E for artisanal assets (post-processed).
- **Icons**: Lucide-react or custom SVG paths for light-weight visuals.
